# YT Music Jukebox

Self-hosted LAN-only music jukebox for Unraid Docker.

## Planned product

- Single host account and local-Wi-Fi guest access
- Automatic song-request approval subject to configurable metadata filters
- YouTube playlists and compatible YouTube Music playlists
- TV player, guest QR request page, host dashboard and configuration page
- Future Fire TV and mobile support

## Status

Project initialized. Application implementation is the next milestone.

## Initial architecture

Node.js backend, browser frontend, persistent configuration and Docker packaging.
